## Estrutura de cada página de case

```
Capa (imagem grande, sangrando)
Título + categoria
Ficha: Cliente · Ano · Papel · Entregas · Ferramentas
Contexto (2–3 linhas)
Processo (3–5 imagens com legenda)
Resultado
→ Próximo projeto
```

A **ficha** é o que serve o recrutador. O **visual** é o que serve o cliente de ilustração. Nessa ordem, a mesma página atende os dois.
